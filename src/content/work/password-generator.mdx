## Overview

A Flask app that generates passwords of 8 to 30 characters from configurable character sets, using Python's `secrets` module for cryptographically secure randomness. Settings persist between sessions.

## Strength analysis

A scoring algorithm weighs length, character variety, unique characters and complexity, then sorts each password into one of five tiers with suggestions for improving it. Debounced API calls keep the feedback instant while you type.
