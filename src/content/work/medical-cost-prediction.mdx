## Problem

Insurance pricing feels opaque. I wanted a model that not only predicts an individual's medical costs but also shows which factors push them up.

## Approach

Using Kaggle's insurance dataset, I encoded smoking status and region, engineered a BMI × age interaction term, and trained a multiple linear regression on an 80/20 split. Coefficient analysis and correlation matrices explain each feature's weight, and a REST endpoint serves predictions from demographic inputs.

## Results

The model reaches an R² of 0.866 on held-out data with an RMSE of $4,567, and identifies smoking, BMI and age as the main cost drivers. I built this pipeline as an ML associate at the AISOC society at KIIT.
