## Overview

The pipeline ingests student data, transforms it with a scikit-learn `ColumnTransformer` (one-hot encoding with rare-category handling, standard scaling), tunes seven regression models with `GridSearchCV`, and keeps the best performer. SHAP values explain each prediction.

## Delivery

A Flask interface validates input and clamps predicted scores to 0 to 100. The app was deployed on AWS Elastic Beanstalk.
