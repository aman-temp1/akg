## Overview

The model takes eight inputs (pregnancies, glucose, blood pressure, skin thickness, insulin, BMI, diabetes pedigree function and age) and returns a risk assessment instantly. Input validation flags unreliable values before they reach the model, and a simple web interface makes it usable without any setup.
